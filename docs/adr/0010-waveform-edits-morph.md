# Oscillators continue each other's cycle and morph between shapes on edits

Replacing one oscillator with another in a live edit (`s` to `t`, a sine to a saw, `440 s` to `lfo s`) clicked by about −27 dB even with the reload declick, for two reasons. Each oscillator type took state only from its own type, and the compiler specializes the same word into different types (a literal frequency gives `FixedOsc`, a modulated one `Osc`, `t` is a band-limited integrator), so most swaps restarted the cycle at an arbitrary point; and the shapes are aligned differently (the sine crosses zero rising at phase 0, the triangle peaks there), so even a carried phase lands on a different value. Every oscillator already runs its phase over −1..1 per cycle, so we made the phase the shared currency: any oscillator now continues the cycle of whichever oscillator it replaces, and when the shape changes it crossfades from the old shape to its own over the same 480 frames as the number glide (docs/adr/0009-number-edits-glide.md), drawing the old shape at the shared phase. Both shapes are continuous in time, so the morph is smooth however they are aligned, and we did not realign the waveforms themselves, which would have shifted phase relationships in existing pieces.

The fading shape is drawn from its formula, with band-limited edges for saws and pulses (oscillators remember their last frequency, pulse width and phase offset for this) and naively for the triangle, whose aliasing over 10 ms is negligible. A band-limited triangle taking over a cycle seeds its integrator at the triangle's value for that phase. Measured against an ideal crossfade between an engine still playing the old oscillator and one that has played the new one all along, swaps among sine, cosine, saw, pulse and naive triangle stay within −138 dB of it and land exactly on the fresh oscillator afterwards; swaps to and from the band-limited triangle differ by about −40 dB, which is the fresh triangle's own sub-sample offset from its first wrap, not a click.

The plain-text editors pair words across an edit by a diff, and an edit that changes the number of words (`110 s` to `110 0 saw`) used to pair them left to right, giving the oscillator's id to its new argument. Unmatched runs now pair numbers with numbers and other words with other words, from the end of the run, because in a postfix language the word doing the work comes after its arguments. The spatial editor's nodes keep their own ids and never needed this.

Morphing costs nothing while it isn't happening: like the glide, an oscillator checks whether a morph is running and otherwise draws its frame in a straight-line leaf. Swaps between non-oscillators and oscillators (`s` to `noise`) remain declick-only: there is no cycle to continue.
